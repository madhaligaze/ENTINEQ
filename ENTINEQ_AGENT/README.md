# ENTINEQ_AGENT

Веб-приложение для владельца и доверенных людей: чат с агентом Claude, который читает и правит файлы и выполняет команды в терминале; админка с пользователями, лимитами, приглашениями и отчётом по расходам. Одновременно это **бэкенд для публичного приложения** [ENTINEQ](../ENTINEQ).

Состоит из двух самостоятельных проектов - у каждого свой репозиторий, `Dockerfile` и сервис в Railway:

| Папка | Что это | README |
|---|---|---|
| [`backend/`](backend) | Аккаунты, лимиты окна и месяца, учёт расходов, агент на Claude Agent SDK, PostgreSQL. Единственное место с ключом Anthropic. | [backend/README.md](backend/README.md) |
| [`frontend/`](frontend) | Страницы (вход, чат, админка) и пересылка `/api` и `/ws` на бэкенд по адресу `BACKEND_URL`. | [frontend/README.md](frontend/README.md) |

Связь: `frontend` → `backend` через переменную `BACKEND_URL` во фронтенде и `ALLOWED_ORIGINS` в бэкенде; `backend` → PostgreSQL через `DATABASE_URL`; публичное приложение приходит в этот же бэкенд по внутреннему каналу с общим секретом `INTERNAL_API_SECRET`. Схема и порядок деплоя - в [общем README](../README.md).
